# Versions: which folder is which

**Point new people at the main folder (the one holding `index.html`, `README.md` and `HANDOVER.md`). That is version 2, the current one. Everything else is history.**

| Version | Where | What it is |
|---|---|---|
| **2: two age groups (current)** | main folder | Ages 3-7 and 8-16, six themed worlds plus "choose your own", markdown-driven emails and social, handover and README. |
| 1: three themes | `_archive-3-themes/` | The site before age groups. Complete and self-contained. Read its `README.md`. |

How version 2 came about, in order:
1. Three-theme party site (version 1), with Meta and SMS landing pages.
2. More worlds were added, some only suited to older children.
3. Age groups added: one landing page with an age toggle rather than two pages, age made a required booking field, URL prefill by `?age=`, and an age-mismatch note.
4. Copy moved into data (`party.copy`), emails and social moved to markdown, build sources and handover written.

Design canvas: the Design file has the current boards plus "Archive: 3 themes" boards.
