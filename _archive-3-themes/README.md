# Archive: three-theme version (no age groups)

This is the site exactly as it was before age groups were added: three worlds (Jurassic Dinosaurs, Construction & Diggers, Deep Sea Exploration), no age toggle, no age question in the booking form.

It is complete and opens on its own: open `index.html` or `book.html`. The `eds-theme/` folder inside is the theme the pages need.

Do not edit this folder. It exists so you can go back. If you only need to hide the age groups on the current site, use the one-line switch (`tiersEnabled: false` in `craftkit-products.js` in the main folder) instead of restoring this archive.

What is NOT archived: the earlier three-world emails and social files were replaced by the markdown-built versions. If you need the old wording, ask for it from the canvas page "Archive: 3 themes" or the earlier chat.
